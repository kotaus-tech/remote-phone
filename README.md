# Видоискатель

Личный проект для трансляции экрана и использования камеры телефона как веб-камеры Windows.

## Статус

- **Этап 1 согласован:** Electron + React/TypeScript для Windows; Kotlin + Jetpack Compose для Android; утверждены тёмная дизайн-система и список экранов.
- **Этап 2 — CI пройдена:** run [#37384956873](https://github.com/kotaus-tech/remote-phone/actions/runs/37384956873), commit `8cc4494` собрал Android APK, x64 native DLL/host и Windows `Setup.exe`; автоматическая установка/удаление и очистка COM-регистрации прошли на Windows runner.
- **Этап 2 — целевое оборудование не проверено:** запуск APK на OPPO Reno 15 и синтетической камеры на Windows 11 ещё не подтверждён. Этап не завершать, к следующему этапу не переходить до заполнения [чек-листа](docs/HARDWARE_TEST.md) и подтверждения пользователя.
- **Ранний PoC виртуальной камеры:** пока только синтетическая камера. Живой поток с телефона — сразу после защищённого транспорта и до основной разработки режима «Веб-камера». Порог ≤100 мс подтверждается только на целевом ПК по чек-листу.
