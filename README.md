# Видоискатель

Личный проект для трансляции экрана и использования камеры телефона как веб-камеры Windows.

## Статус

- **Этап 1 согласован:** Electron + React/TypeScript для Windows; Kotlin + Jetpack Compose для Android; утверждены тёмная дизайн-система и список экранов.
- **Этап 2 начат:** каркас приложений и CI для APK, Windows Setup.exe и нативной части.
- **Ранний PoC виртуальной камеры:** синтетическая камера — в каркасе; живой поток с телефона — сразу после защищённого транспорта и до основной разработки режима «Веб-камера». Порог ≤100 мс подтверждается только на целевом ПК по чек-листу.
