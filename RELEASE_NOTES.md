# Видоискатель v0.2.1 — фикс-раунд 2: моргание, «Максимум» на портретном экране, поворот камеры

Сборки по итогам ретеста v0.2.0 (Этап 5b в `docs/HARDWARE_TEST.md`).

## Исправлено

**Моргание чёрным (оба режима) — главная причина найдена:** предпросмотр переподключал видеопоток на каждую телеметрию (раз в 2 секунды) из-за пересоздаваемого React-колбэка. Теперь подключение происходит только при реальной смене элемента. Дополнительно:

- Сеанс «Экрана» больше не обрывается через 15 секунд (таймер «первый кадр» считал только NV12-записи, которых для экрана и не должно быть).
- Ошибка одного кадра (сбой декодирования, смена размера) больше не рвёт весь сеанс — кадр пропускается с предупреждением.

**Качество «Максимум» на портретном экране:** ошибка «Недопустимый размер видеокадра 1080×2374» убрана — лимиты теперь «любая ориентация: до 4096 по стороне и до 4K по пикселям». Портретные экраны передаются в нативном разрешении.

**Поворот телефона в режиме «Веб-камера»:** при физическом повороте в landscape захват камеры перезапускается (2–3 секунды заминки — норма), и предпросмотр с OBS-картинкой разворачиваются.

**Прочее:** NV12-конвертация гоняется только для веб-камеры (экран больше не тратит CPU на неё); предпросмотры не искажаются ни в одной ориентации.

## Важно

⚠️ Исправления **физически НЕ проверены** — нужен повторный прогон. Управление с ПК (Milestone 2) ещё не реализовано. Полный чек-лист проверки — «Этап 5b» в `docs/HARDWARE_TEST.md`.
