# Видоискатель v0.2.0 — фикс-раунд после первого физического теста

Первые сборки после физического теста OPPO Reno 15 + Windows 11 (Этап 5a в `docs/HARDWARE_TEST.md`).

**Скачивание:** ниже два файла — APK для Android-телефона и установщик для Windows 11 x64. Оба собраны этим же зелёным CI из коммита с меткой `v0.2.0`.

## Исправлено по результатам теста

- Надпись «Ожидаем видеопоток» больше не перекрывает живую трансляцию: телефон шлёт `session-info` при открытии data channel, режим восстанавливается из телеметрии.
- Поток веб-камеры отображается на своей странице «Веб-камера»: живой предпросмотр, зеркало, выбор качества, остановка, телеметрия.
- Меньше моргания чёрным: переиспользование PeerConnection при reconnect/ICE restart (до 3 попыток), NV12-очередь «последний побеждает», порог синтетической заглушки поднят до 3000 мс.
- Битрейт и резкость: `degradationPreference` — MAINTAIN_RESOLUTION для экрана, MAINTAIN_FRAMERATE для камеры.
- Захват экрана по фактической ориентации окна — крупный предпросмотр и в портрете, и в ландшафте.
- Форматы камеры: предпочтение 16:9.

## Важно

⚠️ Исправления **физически НЕ проверены** — нужен повторный прогон на устройстве.

Удалённое управление с ПК (жесты, Milestone 2) ещё не реализовано.
